Viva Voce — 5 Marks

🎓 Key Concepts to Explain

Q: What is Spring Boot?
A: A Java framework that auto-configures a web server (Tomcat), REST API handling, and database connection. We just write business logic — Spring handles the rest.
Q: What is JPA / Hibernate?
A: JPA is Java Persistence API — it maps Java classes to database tables. Hibernate is the implementation. We write Java, it writes SQL automatically.
Q: How does frontend connect to backend?
A: JavaScript uses fetch() to send HTTP requests to Spring Boot REST endpoints. Spring returns JSON. JS reads the JSON and updates the page.
Q: What is REST API?
A: REST = Representational State Transfer. It's a standard way for frontend and backend to communicate using HTTP methods: GET (read), POST (create), PUT (update), DELETE.
Q: What is @RestController?
A: A Spring annotation that marks a class as a REST API handler. Every method automatically converts its return value to JSON and sends it as an HTTP response.
Q: What is the difference between Service and Controller?
A: Controller handles HTTP (what URL, what method). Service handles business logic (can we book? how much does it cost?). Separation of concerns.
Q: What database is used?
A: H2 — an in-memory SQL database. It starts with the app, loads seed data from data.sql, and is accessible at /h2-console. No installation needed.
Q: What is @ManyToOne in Booking.java?
A: It defines a database relationship — many bookings can belong to one event. JPA creates a foreign key column event_id in the bookings table automatically.
